# Meeting Helper app

Tauri v2 + React + TypeScript desktop app. See the [project README](../README.md) for setup and testing.

```bash
bun install
bun run tauri dev
```

Layout: `src/lib` (db, search, pipeline, providers, OBS client, settings), `src/screens`, `src/components`, `src-tauri/src` (ffmpeg, secrets, uploads).
